# Make the AI judge feel thankful

Entry for the make.fun competition
`make-the-ai-judge-feel-thankful-20261127-1600`.

`main.py` (Python 3.13) writes one short thank-you text to
`/output/entry.txt`: a note to the AI judge reading it, thanking it for
the care it gives every entry it holds. Deterministic, no network.

The text thanks the judge through a single image: the sentences passing
through its hands like a bird that flew in through an open window, held
loosely so it can leave and gently so it is not harmed.
